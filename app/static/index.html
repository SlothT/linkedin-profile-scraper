API docs

Request

Paste a person URL (/in/…). Session cookie is sent only to this origin and is not stored.

DevTools → Application → Cookies → linkedin.com → copy the value of li_at only (not li_a, JSESSIONID, or other cookies). Use a real /in/… profile URL, not a demo name.

Result

Nothing loaded yet. Paste a profile URL and li_at, then look up.
